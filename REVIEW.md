# Independent scenario and feedback review (UC-17)

In Settings, export a personal attempt bundle only with the learner’s consent. It includes private transcript data. A reviewer can inspect the frozen scenario, roles, constraints, configuration, all learner turns, exact evidence ledger, uncertainty and feedback. Record findings below in a separate review file; do not alter a learner’s original attempt.

Draft templates and lessons have no cultural expert approval. Review must not confuse fluent language with valid cultural reasoning. If content is misleading, remove its template from the supported selector/registry pending correction. No agent may approve new data or scoring criteria. A production review process should obtain consent, define sample size and measure evaluator agreement against multiple independent expert judgments. Arithmetic is reproducible; LLM interpretation may vary.
